# Changelog

All notable changes to this project are documented here, newest first.
This project has no released versions or version branches (see
[`SECURITY.md`](SECURITY.md)) — entries are grouped by date instead of
semver. For the full reasoning behind each change (why, not just what),
see [`STATUS.md`](STATUS.md); this file is the terse index.

## 2026-09-10 — Repo hygiene

- Added `SECURITY.md`, `CODE_OF_CONDUCT.md` (Contributor Covenant
  v2.1), and `CONTRIBUTING.md`.
- Rounded out `.gitignore` (editor configs, general `*.log`, lint/
  coverage cache dirs) after auditing that nothing sensitive was ever
  tracked.
- Added an MIT `LICENSE`.
- Replaced the stale "Claude Code handoff package" `README.md` (written
  before the build started) with a real project README.

## 2026-09-09 — Sprint 24 and its accessibility follow-up

- **Fixed unassociated form labels across the authenticated app**
  (`7ee1903`) — 18 files where a `<label>` was a sibling of its input
  with no `htmlFor`/`id` pairing, so screen readers had no accessible
  name for the field. Found and fixed on sign-in/sign-up during Sprint
  24; closed out across the rest of the app immediately after.
- **Sprint 24 — Security / Performance / Accessibility / Pilot
  Hardening** (`16c207a`) — the roadmap's last sprint. A systematic
  tenant-isolation fuzz suite covering all 15 GET-by-id resource types
  (no leak found); real structured JSON request logging; three real
  bugs found and fixed (a missing audit event on report export, a
  Redis outage that took down entire requests instead of degrading, an
  unbounded file-upload DoS gap); Northstar demo data for both named
  orgs, seeded through the real API.

## 2026-09-09 — Sprints 22–23: Ask DataLume and Reporting

- **Reporting & export** (`f9abcb8`) — PDF/XLSX/CSV export for all five
  named report types, generated by the (now-real) worker's background
  loop rather than synchronously in the request.
- **Ask DataLume** (`967086e`) — grounded natural-language Q&A over
  property data: seven typed tools wrapping already-built deterministic
  engines, deterministic tool selection, and an LLM interpretation
  layer (Anthropic, behind a Null-provider fallback) that never gets
  database access.
